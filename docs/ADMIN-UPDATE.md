# EarthAI 管理平台、默认资源与 Markdown 更新

## 管理员与用户分离

首次启动创建 `admin / admin`，密码只保存 scrypt 哈希，首次登录必须改为至少 8 位的新密码。重启不重置密码，不重复创建初始管理员。注册只能创建普通用户，用户不能从个人资料接口设置角色。管理员可创建、修改、删除用户、设置管理员、重设密码和启停账号，支持批量操作。初始 admin、当前管理员及最后可用管理员受保护。

管理员侧栏仅有系统概览、智能体管理、用户管理、知识库管理、技能库管理、项目管理、服务器管理、模型供应商管理、定时任务管理、告警管理、界面管理。管理员不显示聊天、个人空间或执行中心，也不能从 API 或引擎绕过角色限制运行用户任务；退出与改密位于管理侧栏底部。

停用、提升管理员、重置密码或删除账号时，后端查询全部活动任务，不受最近 200 条运行记录限制；请求取消并等待后台任务结束后再清理数据。会话撤销，调度器跳过受限账号；正在运行的引擎在继续模型轮次和工具执行前再次检查。已经发出的远端副作用仍无法自动回滚。

## 默认资源与批量管理

平台默认模板与用户私有资源分开存储。管理员维护七类默认资源：智能体、知识库、技能、项目、服务器、供应商/模型、定时任务。增删改和文档变更在同一 SQLite 事务中同步所有普通用户；新用户自动继承。每用户默认副本保持稳定 ID，关联资源按用户重新映射，避免偏好与会话引用失效。

普通用户默认配置只读，可阅读、检索、选择和按既有控制等级使用；不能修改、删除、启停、替换凭据、同步模型写回或增删默认文档。自建资源原有功能保留。个人智能体排序保存到用户侧排序表，不修改平台模板。

每类默认管理支持选择、全选当前结果、已选计数、批量修改、批量删除确认及 JSON 批量新增。知识文档可全文阅读、编辑、逐项或批量删除，保存后重建索引。供应商支持模型行增删改、默认模型和批量替换模型列表。用户支持批量角色/启停/删除；告警支持全员查询、编辑、解决/重开、严重度批改与删除，处理直接反映到所属用户。界面管理以整套品牌配置保存、恢复、导入和导出实现批量维护。概览与审计为只读，不提供删除日志等伪操作。

默认服务器与供应商的共享凭据不回显，发布即授予所有普通用户使用相应连接或额度的能力，应使用最小权限并确认授权。默认任务新建关闭；启用后每个普通用户都将独立调度，请评估重复调用与成本。删除依赖会清理对应引用并关闭受影响计划，不自动换到其他目标执行。

旧版未经修改的内置资源可接管为默认副本；有自定义改动的私人资源保留。旧知识库不仅比较名称、大小，还重组分块逐字核对正文；同大小但已修改的手册不会被覆盖。

## 各 50 项实质内容

初始默认目录为 50 个智能体、50 项技能、50 个知识库，100 篇已索引中文手册。每个智能体绑定同领域技能和知识库，手册含具体输入、只读证据步骤、判断、风险、审批恢复及验证。

在原有集群巡检、Pod、Linux、DNS、发布回滚、容量、安全、备份、告警和事故 10 个领域外，新增 Deployment、StatefulSet、DaemonSet、Job/CronJob、HPA、PDB、Quota、LimitRange、调度亲和、拓扑、污点、探针、Ingress、CoreDNS、CNI、CSI、etcd、控制面、kubelet、containerd、证书、镜像仓库、Helm、GitOps、MySQL、PostgreSQL、Redis、MongoDB、Kafka、RabbitMQ、Nginx、HAProxy、systemd、句柄/PID、时间同步、防火墙路由、Prometheus、Grafana、Loki、OpenSearch 40 个具体领域。

可用指真实指令、绑定和检索内容已接入引擎，不是50个空标题。实际诊断仍需配置模型及授权目标；不假装已有数据库专用工具、监控服务或远端命令。原生工具不支持的 Kubernetes 资源会明确需当前授权 SSH 上已有 kubectl；缺少能力只报告证据缺口，不能绕过审批或虚构成功。

## Markdown、帮助与品牌

聊天与文档使用固定 `react-markdown@10.1.0`、`remark-gfm@4.0.1` 渲染 GFM 表格、对齐、列表、引用、删除线、任务列表等。代码块保留语言和复制功能；窄屏表格在自身区域横向滚动。不执行原始 HTML，不自动下载远程 Markdown 图片，恶意协议不变成可执行链接。逐字符流式和未闭合语法不会崩溃。

右上问号跳转 `/help`，按角色展示管理员 11 模块或用户 12 模块的详细指南，支持目录锚点与搜索。每模块含功能、字段、步骤、权限、风险和失败排查，而不是三条简短弹窗。

界面管理提供系统图标、favicon、名称、副标题（原 WORKSPACE）、宣传语、标题/副标题的字体字号颜色、即时预览与整套发布。图片仅本机上传 PNG/ICO/JPEG/WebP，限制2MB，拒绝SVG及外链；字体使用已本地化或系统字体。登录页、侧栏、聊天作者、浏览器标题、favicon及manifest随品牌配置生效；品牌图片与数据库、上传文件、主密钥一并备份。

## Docker 与监听要求

运行时镜像不创建 earthai 账号，`/etc/passwd` 与 `/etc/group` 只保留 root，`USER root`，Compose 指定 `user: "0:0"`。原配置没有 privileged 字段，按要求未补加，Docker默认仍为非特权容器；root 不等于 privileged。

应用、Compose端口映射、Vite开发/预览、systemd与Nginx监听均为 `0.0.0.0`。健康检查及代理上游的 `127.0.0.1` 是目标地址，不是监听绑定，不应改成万能地址。保留 `no-new-privileges`，丢弃其他 capabilities，仅给 `DAC_OVERRIDE/FOWNER` 以兼容旧非root数据卷的访问和权限维护；不挂载宿主Docker socket。root运行会扩大风险，应限制内网访问。
