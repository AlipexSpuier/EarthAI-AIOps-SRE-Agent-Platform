# EarthAI 界面优化验收

## 本轮修复

- 取消聊天页固定最小高度与外壳高度叠加；应用外壳固定视口，聊天只滚动消息区，管理页只滚动主内容区。长内容不被隐藏。
- 新对话欢迎区与输入框适配窗口高度，压缩纯装饰空间，缩短窗口时自动收紧推荐项；短内容不再因硬设 550px 工作台而撑出滚动。
- 智能体不再触发页顶配置栏；智能体、项目、服务器、模型和控制等级都从输入框旁的触发按钮展开。
- 所有管理页和聊天的原生 select / datalist 替换为统一自定义选择器。浮层与按钮间隔 8px，自动上下翻转、左右约束，最大高度 360px，仅选项列表滚动。
- 供应商与模型分成独立选择器；模型按当前供应商过滤，切换供应商重置默认模型，支持搜索与明确确认自定义模型名。保留真实请求中的 provider_id / model 字段。
- 选择器支持键盘上下移动、Enter 确认、Escape 关闭、选中回焦、外部点击关闭与 FormData。
- 个人资料、头像、主题、默认执行等级和退出登录统一到左侧「偏好设置」。左上工作空间和右上头像不再伪装为同一用户中心入口，左下身份信息仅展示。
- 左侧「AI 对话」是新对话唯一泛入口；历史对话的重命名与删除统一在历史列表。删除页顶、空态、概览、搜索和帮助中重复的新建跳转。
- 8 个管理页创建入口各保留一个，移除空态及目录内的同功能按钮。个人空间保留上传区唯一按钮和拖拽，知识库文档上传保留独立业务入口。
- 概览移除宣传横幅和重复泛跳转，保留真实统计、任务执行记录、趋势、状态和告警信息；逐条任务、服务器诊断等携带上下文的操作保留。
- 长文件名、MIME 与表格列允许合理换行，移动端知识库目录不再横向滑动；移动侧栏关闭时不占焦点，打开时支持 Escape 与焦点约束。

## 视口验收

真实无头 Chromium、CSS 100%、deviceScaleFactor=1，使用隔离数据库，不改动交付数据库中的用户、文件或连接配置。

1920×1080、1440×900、1366×768、1280×720、1024×768、820×600、390×844、360×640 八种视口均满足：

- 新对话无多余横向或纵向滚动。
- 输入框完整留在视窗内。
- 文档宽高不超过视窗。
- 无浏览器 JavaScript 运行时错误。

管理页对短列表/空态无多余滚动；长文档、长列表、设置表单与概览的正常纵向内容保留主内容区单一滚动。菜单长列表可局部滚动，这是浏览选项所需，不是页面溢出。

## 回归结果

- 前端单元/交互测试 13 项通过。
- TypeScript 检查和生产构建通过。
- 后端 40 项测试通过；1 条现有上游弃用警告。
- 浏览器 UI 回归全部通过，原始测量见 `ui-verification.json`。
- 原真实 HTTP 端到端流程仍通过：注册、供应商表单、四轮 Agent、三次工具、切页不断执行、刷新恢复、报告下载。
- 未增加真实模型费用或操作用户服务器；模型和资源为测试配置。
