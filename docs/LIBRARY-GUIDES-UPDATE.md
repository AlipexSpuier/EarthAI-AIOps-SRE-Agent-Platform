# EarthAI 双区工作台、指南维护与统一镜像

## 技能库、知识库独立滚动

用户技能库的「全部技能」目录与「SKILL DOCUMENT」正文、知识库的「知识库目录」与「KNOWLEDGE COLLECTION」详情不再被内容共同撑高。页面按视口剩余高度分配，目录与正文各自滚动，滚动其中一栏不会移动另一栏或整个页面。

桌面和平板保留双栏。手机使用上方有限目录、下方详情，两区仍分别可滚；短屏采用合理最小高度保证控件可达，不因数十项资源无限拉长页面。四个滚动区均可键盘聚焦。切换技能或知识库仅将右侧正文回到开头，目录位置不被重置。

知识文档列表、库内全文检索与阅读请求按库 ID 和请求序号隔离，切库后不展示旧库的迟到结果。默认资源只读、自建资源原 CRUD 行为保持。

## 查找知识库目录

统计区下方「本地全文索引 · 真实文档内容」右侧新增「查找知识库名称或描述…」，窄屏自然换行。它只按库名称和描述筛选目录，忽略大小写和首尾空格，目录显示匹配数/总数，无匹配可清除条件。

此处与右侧「知识库检索关键词 / 全文检索」分开：查找目录不自动换库，不清空当前库的全文结果；当前阅读库不在筛选结果时仍保留正文并提示。点击匹配目录项后才实际切换库。

## 管理员维护两套使用指南

两角色顶部现在均显示问号与可见的「使用指南」文字，紧邻安全说明，手机也保留文字。管理员打开自己的指南后，点击「管理使用指南」进入 `/admin/guides`；仍保留原11项管理主导航，不增加分散的入口。

管理页可切换「管理员指南 / 普通用户指南」，每套支持章节新增、阅读预览、编辑、删除、搜索、排序字段和批量删除。字段包括固定章节地址、标题、摘要、本地图标、排序及 Markdown 正文，提供编辑/预览/分栏模式。地址创建后不能变更，修改内容不会破坏既有链接；删除会使该节旧链接失效。

指南存于 SQLite `help_guides`，初始从 `backend/guide_presets.json` 完整导入23节（11管理员、12普通用户），只初始化一次。之后修订、删除或清空目录不被重启覆盖或复活。管理员管理两套，普通用户只能读取本角色，不接受客户端参数越权读取管理员内容。写操作留审计；批量先校验全部 ID，在一个事务中删除。

阅读仍为独立 `/help/:section`，一次只挂载一章。支持目录搜索、上一节/下一节、刷新和历史导航；章节被删除或整套为空时显示明确提示，不崩溃或循环跳转。其他读者重新打开或刷新即可看到最新内容，不虚称已实现跨设备实时推送。

## 镜像统一为 earthai:latest

Compose 明确指定 `image: earthai:latest`，普通 Compose 构建和手动 `docker build -t earthai:latest .` 均使用同一名称。构建核验、升级准备/应用脚本及当前交付文档已统一。回退读取原容器的确切镜像 ID，不再硬编码某个过时版本标签；旧验收报告中记录的旧标签是历史证据，不改写为新构建。

本轮已构建 `earthai:latest` 并在无网络临时容器中验证 root-only、0.0.0.0、默认管理员、50套资源和双角色指南。此前 root 用户、0.0.0.0 监听、非特权默认及本地静态资源约定均保留。

- 后端480项、前端55项测试通过；Ruff、TypeScript及生产构建通过。唯一后端警告是既有Starlette/AnyIO弃用提示，前端仍有主包超过500KB的性能建议，不影响构建。
- 指南新增17项权限、字段校验、种子完整、重启保留、删除不复活、批量原子性及空集稳定专项通过。
- 真实Chromium使用50项目录、180行技能正文和35份知识文档，验证1440px、1024px、390px独立滚动。三种宽度的页面滚动高度均等于可见高度，左右/上下栏各自存在实际溢出和滚动，不是只设置了CSS却没生效。
- 管理员通过真实表单新增/编辑/删除两套指南，对应角色在独立地址刷新后可读，普通用户无管理入口且接口403。
- 上轮双角色指南分页、深浅主题无彩色输入描边/阴影保留、自动同步模型及无公网静态资源回归通过。
