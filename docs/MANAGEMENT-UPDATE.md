# EarthAI 智能体与运维管理更新

## 已上线的功能

### 本地与远程智能体

创建及编辑表单新增类型选择。本地智能体继续使用模型、系统指令、技能及知识库执行任务；远程智能体填写名称和 HTTP(S) 网页链接即可，卡片在新窗口打开该网址。

远程链接不会由后端抓取，也不会转发 EarthAI 的账号、会话或服务器凭据。远程智能体不能被聊天或定时任务当作本地执行器。链接拒绝可执行协议和内嵌用户名密码；新窗口使用 `noopener noreferrer`。

### 永久自定义排序

智能体页「调整排序」可拖拽，也可使用上移/下移按钮。点击保存后，完整顺序以账号为范围原子写入数据库，刷新或重新登录仍保留；取消会丢弃本次草稿。

新增智能体排在末尾，编辑内容不会改变排名。旧智能体缺少排序字段时会保留已存在的有效排名，其余按创建时间从旧到新追加。并发编辑不能把最新排序覆盖回旧值，过期或不完整的排序列表会明确报错。

### SSH 首次自动信任

新增 SSH 服务器默认开启「首次连接自动信任并保存指纹」。首次实际握手时原子固定收到的 SHA256 指纹，不必手动复制；后续指纹不一致会拒绝连接，绝不静默覆盖。

这属于首次信任（TOFU），不是关闭主机校验。它无法独立排除首次连接的中间人攻击；高安全要求下可关闭自动信任，并填写经独立渠道核实的指纹。更换主机或端口会清除原指纹。Kubernetes TLS 校验不受影响。

### 审计日志时间筛选

系统概览底部可选最近 24 小时、7 天、30 天、全部时间或自定义起止时间。输入按浏览器本地时区解释并转换为 UTC，后端直接按账号及实际时间筛选，最多返回 100 条；边界包含在结果内。

空的自定义区间、无效时间及结束早于开始会给出错误提示。列表展示完整本地时间，移动端日期控件可换行，不会撑宽页面。

### 网站图标

补齐 `favicon.ico`（16/32/48）、32px PNG、180px Apple Touch 图标、192px/512px 应用图标及 `site.webmanifest`。均为实际图片或 manifest 响应，不是单页应用的 HTML 回退。
