# EarthAI 帮助分页、输入样式与供应商同步

## 帮助指南每节独立

管理员 11 节、普通用户 12 节详细指南均保留。目录入口改为 `/help/:section`，每次只挂载该章节正文，不再把所有模块拼成一条长页面，也不是把其他章节用 CSS 隐藏。

`/help` 按角色进入首节；提供上一节、下一节、章节名称和进度。浏览器刷新、前进、后退均以 URL 恢复章节。搜索覆盖本角色全部内容，只筛选可点击的章节链接，不把所有命中的正文堆在一起；零命中不清除当前阅读内容。管理员和普通用户目录仍隔离。

## 移除输入的彩色描边，保留阴影

清理全局文本输入、搜索、密码、聊天输入区域及自定义选择器的彩色 hover/focus border 和内层 outline。中性默认边界、原有绿色 box-shadow 和控件背景不变；管理员表单额外定义的输入轮廓也已清理。浅色和深色主题均使用相同规则，普通按钮、链接、开关等键盘可访问提示不受影响。

登录/注册保留一枚页面自带的密码显示/隐藏按钮。添加针对原生 `::-ms-reveal`、`::-ms-clear` 的隐藏规则，避免支持这些按钮的浏览器再叠加一枚眼睛；按钮通过 `aria-pressed` 标明显示状态。浏览器扩展自行注入的密码管理按钮不由项目控制。

## 新增供应商自动同步

管理员默认供应商与普通用户自建供应商，均只需填写名称、Base URL、API Key，模型列表和默认模型可留空。后端先保存配置，再只请求一次供应商 `GET /models`，不调用聊天模型；按返回顺序去重、过滤有效模型，成功后将第一个模型设为默认。

同步失败、超时、格式异常或空目录不会回滚已保存的供应商，也不会伪造模型。接口返回明确 `model_sync` 状态，页面卡片和提示说明失败及重试/手填路径。管理员的默认配置仍自动同步给用户，普通用户对继承的默认供应商不可修改。

卡片上的手动同步使用：

- 普通用户：`POST /api/providers/{id}/sync-models`
- 管理员：`POST /api/admin/defaults/providers/{id}/sync-models`

手动同步保留仍在新目录中的默认模型；没有有效默认时取首个。同步失败保留原模型目录，编辑保存不自动访问供应商。同步期间若配置已更新或删除，不用旧结果覆盖新配置。批量新增供应商同样只对每个新条目同步一次，并返回失败提示。

- 使用本机受控模型目录验证两种角色新建无需模型、同步恰好一次并选首个；503/空目录时配置与重试入口仍存在，没有调用付费模型或SSH。
